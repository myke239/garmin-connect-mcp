Extract executable bundles together. Installation and removal preserve separate Garmin credentials and journals. Review the [installation guide](https://github.com/myke239/garmin-connect-mcp/blob/main/docs/getting-started/installation.md) and [distribution verification](https://github.com/myke239/garmin-connect-mcp/blob/main/docs/development/distribution.md).
